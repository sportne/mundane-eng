# YAML requirement examples

The checked-in examples include a small conformance source, a vaccine-monitoring
project and an operational corpus. Each uses the YAML 0.3 profile. Run validation
from the repository root with `build/maintained/mundanereq-validate examples/yaml/vaccine-monitoring`.

IDs are human-authored; paragraph/math content and decomposition links remain
explicit. YAML 0.4 examples with project declarations are under
[attributes](../attributes/README.md). See the [source contract](../../specification/0010-requirements-yaml-0.3.md).
