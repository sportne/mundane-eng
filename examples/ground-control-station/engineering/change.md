# Worked GCS change evidence

Run make change-verify. The maintained
[workflow](../../../scripts/check-change-workflow.py) retains before/after source,
compiled inventories and analyses under build/gcs-change/. The scenario ledger
records observed classifications, differences and prospective paths; each selection
records the actual digest from that execution.

Eight real source/native-input mutations exercise telemetry timing, host power
assumptions, a removed host cable, CycloneDX dependency metadata, a procedure timing
criterion, a disputed reviewer decision, formatting only and an unsupported family.
The dependency case revises native dependency declarations; it does not claim to
build a new server executable. The disputed decision deliberately retains the old
signature so changing authored words cannot fabricate reviewer acceptance.

Procedure and formatting changes both invalidate the evidence's exact procedure
selection. Assurance and operations are also directly stale because both explicitly import
the old procedure. Equipment remains unchanged in that chain. For the telemetry
requirement mutation, equipment is prospectively reachable through architecture but
has no direct staleness: its own selected architecture/configuration pins still match. Removing the host cable makes its
directly dependent budget stale. Changing the selected assurance makes operations
stale. Unsupported input leaves coverage incomplete.

An explicit rerun of the revised procedure creates new evidence at the new pin;\nthat new consumer requires reassessment and the retained assurance is stale.\nThe workflow also checks deterministic reconstruction with retained native bytes,
duplicate/path/pin rejection, omitted dependency visibility, unavailable provenance
and a JVM consumer whose classpath excludes YAML/source parsing. Native resources
explicitly selected by a baseline remain necessary bytes. Existing impact fixtures
retain their established prospective meaning. These checks are fixture evidence,
not UAV operational qualification or release approval.
