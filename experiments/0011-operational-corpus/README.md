# Experiment 0011: Operational Corpus and Frozen Trial Protocol

Status: Corpus and protocol selected; execution belongs to TC-0702 and TC-0703

Date: 2026-08-29

Roadmap task: [TC-0701](../../roadmap/closed/task-0701-select-a-larger-corpus-and-trial-protocol.yaml)

## Result

The selected trial input is an original, fictional 60-requirement watershed
monitoring corpus under the project BSD 3-Clause License. It contains 54
relationships, six roots, three requirement levels, and six subject files. It
materially exceeds the previous 21-requirement sustained-authoring corpus and
provides repeated multi-level paths rather than a single illustrative graph.

[Provenance](provenance.md) records the exact public revisions inspected and
why none was imported. The [frozen protocol](trial-protocol.md) fixes
independent-author and multi-author/layout scenarios, observation categories,
evidence rules, and stop conditions before execution. The participant-facing
[task sheet](independent-author-tasks.md) contains no project-history guidance;
the separate [oracle](expected-results.md) is withheld during TC-0702.

## Pressure represented without new syntax

The corpus exercises stable IDs, statements, rationales, multi-level
decomposition, broad source discovery, repeated trace queries, file moves,
concurrent edits, and meaningful numeric changes. It deliberately does not add
allocation, safety level, arbitrary attributes, verification artifacts,
approval state, views, or a glossary. Those remain distinct model-pressure
questions rather than assumptions hidden in a scale corpus.

## Decision

Use this corpus for TC-0702 and TC-0703. Its domain content is sufficient for
source and workflow tasks but is not asserted to be a complete or correct real
system specification. Trial results must distinguish mundane-req learnability
from participant domain expertise and must not be presented as statistical
usability evidence.
